## 3. 根因分析：71 课判据缺"确认后反扑撤销"

### 3.1 问题机制

71 课判据在转笔延伸三笔破位时 `return 'confirmed'`，但**无后续窗口观察反扑**：

```
bi#103（Dn 3841.49→3822.36）: 转笔
bi#104（Up 3833.72→3822.36）: 第 2 笔 → 'extended'（破起点 3841.49，判据作废）
  ... 但之后 stdSeq 吞并继续 ...
bi#106（Up → 3858.31）: 第 4 笔高点，突破转笔起点 3841.49
  → firstBiBreak 早已返回，没机会观察
```

bi#106 的 3858.31 是**同一根笔**在 extended 判定之后出现的（firstBiBreak 先于吞并执行，extended 时
for 循环在 i=104 处即 return，**i=106 的高点从未被扫描到**）。

## 4. 建议修复方案（待用户拍板）

### 4.1 推荐：N1 有限反扑窗口

在 `firstBiBreak` 中，`confirmed` 后不是立即 return，而是继续扫描相邻 N=1 笔：
若这 1 笔为段向笔且**破转笔起点（假设分界点极值）**→ 撤销确认（走 extended 吞并路径）；
窗口结束 → 定案。

```
confirmed = false; window = 0;
for (i = prev.biIndex + 1; ...) {
  if (与转笔同向 && 破转笔终点) { confirmed = true; }
  if (与段同向 && 破转笔起点) {
    if (!confirmed) return 'extended';     // 先破起点 → 作废（已有）
    if (window <= N) return 'extended';    // 确认后立即反扑 → 撤销（新增）
  }
  if (confirmed) window++;
}
return confirmed ? 'confirmed' : 'none';
```

副作用量化：07-01/07-03 处**同样被反扑的单笔段**（Up[53..53]、Dn[57..57]）也会
被撤销延伸到真极值（07-06 10:55 / 07-06 13:55），这在缠论语义上**是正确的**
（71 课"当下程序"：分界点不满足则原段延续，直到找到真正不被反扑的极值）。

### 4.2 备选：维持 keep（严格 71 课字面）

点 2 的"顶在 Dn 段内"保持不变。优势：改动最小；劣势：段终点偏离真极值约 2 天，下游
（段中枢/买卖点/前端段绘制）基准偏移。

### 4.3 备选：无限反扑（fix2）

副作用太大（06 月结构全面重写，段数 33→27），**不推荐**。

### 8.4 架构根源（为什么"做不到极值"）

`findSegmentEnd` 是**单遍流式"首个命中即 return"**，而"终点 = 极值"是**全局属性**。
71 课"假设-验证-淘汰"程序只实现了"验证命中"，**未实现"淘汰"**：

| 定案路径 | 触发处 | 反超淘汰 |
|----------|--------|----------|
| case1（无缺口分型） | `first!==null` | ❌ 无（命中即 return） |
| case2（有缺口分型） | `first!==null` | ✅ 有（`case2Confirmed` 失效检查） |
| 71 课判据 | `first===null` | ❌ 无（命中即 return） |

case2 天然正确正是因为它有失效检查——其它两条路径缺的正是同一个"候选被反超即作废"的机制。

### 8.5 淘汰窗口的正确语义（fix4 方向，待预演）

**反超淘汰不能扫到数据尽头**（会把 06-18 的 4117.45 顶被 06-29 的 4143.31"反超"而把段拉成一整条）。
正确语义：候选终点 T 之后的走势，**在"反向段自身确认"之前**若出现反超（Up 段被更高顶 / Dn 段被更低底）→ T 作废、段延伸；**反向段一旦确认，反超归属新段、不影响 T**。

- 例（应作废）：`Up[124..136]` 终点 3967.59 在反向 Dn 段确认前被 3968.48 反超 → 段应延伸（fix2 未处理，实为 case1 路径缺淘汰）；
- 例（不应作废）：`Up[14..32]` 终点 4117.45 的反向段（Dn[33..37]，4070.17 底分型）先确认，此后 4143.31 归属新段 → 4117.45 成立。

实现形态：case1 与 71 课判据定案前**嵌套等待"反向段确认"**（递归/候选检验器完整形态），或等效的"事后极值校验迭代"（段输出后校验终点=段内极值，不满足则回退重划）。**N1/N2/N3 有限窗口方案已撤回**（无理论依据的参数拟合）。

### 8.7 最终考证结论（推翻 §8.1 / §8.5 / §8.6，用户确认定案）

#### 8.7.1 原文考证："命中即定案、永不回头"是缠论定性

| 课程 | 原文要点 | 含义 |
|------|---------|------|
| 72 课 | "59 并没有完成，因为目前没有满足 59 段被 100% 破坏的标准。而 **58 以及以前的所有段都是唯一的，不可更改的**——因为，符合标准了，就这么简单。" | 段一旦符合结束标准（被破坏确认）即**定案、不可更改**；未完成段才处于延伸状态 |
| 71 课 | "第三笔破点第一笔的结束位置，那么，**新的线段一定形成，前线段一定结束**。" | 71 课判据命中即定案是原文的绝对语气 |
| 65 课 | "只有构成有重叠部分的前三笔，那么必然会形成一线段"；"当下的分析和事后的分析，是一样的" | 三笔重叠即新段形成（定案机制）；规则同一、结果唯一 |
| **78 课** | "如果那向上笔突破线段 B 的高点，这时候就会出现，**线段的开始点并不是最高点**的情况。" | **原文明确承认"段界不是极值"是正常现象**（配图讲解），非待修正错误 |

**结论**：§8.1"段终点必须是段内极值"的用户裁决**不构成缠论原文的线段语义**——"极值"是走势类型/直觉层面的期望；线段 = 特征序列结构，端点 = 分型/71 课判据极值，**可以不等于段内全局极值**（反扑创新高属于**新段的内部走势**，78 课明示）。
