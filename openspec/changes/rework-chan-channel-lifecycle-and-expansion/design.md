# Design: rework-chan-channel-lifecycle-and-expansion

## 1. 核心架构与设计目标

本设计彻底解决当前中枢算法在宽幅震荡行情中出现的“无界延伸 + 贪婪合并 + 级联扩张”导致的 139 笔超长中枢问题。
核心原则：**以缠论第 20/29/52 课原典数学定理为唯一依据，建立严格的顺序确认生命周期状态机。**

```
笔/段序列 (confirmed & valid)
  │
  ▼
【顺序确认状态机 Sequential Confirmation State Machine】
  │
  ├─ 1. 基础中枢确立 (Formation)
  │     寻找前 5 笔（或 3 段）满足 zg > zd 的重叠区间，确立初始 [ZD, ZG]
  │
  ├─ 2. 中枢延伸状态 (Extending)
  │     逐笔/逐段输入 u_k：
  │     • 触及判定：high_k >= ZD 且 low_k <= ZG ──> 归入中枢延伸，更新全量公共交集与极值
  │     • 扩展升级：若累计震荡达 9 单元 (3+3+3) ──> 标记/升级为更高一级中枢 (expanded: true)
  │
  ├─ 3. 离开与闭合状态 (Departing / Closure)
  │     若 u_k 完全脱离 [ZD, ZG]：
  │     • 回抽触及 (u_{k+1} 触及 [ZD, ZG]) ──> 判定为中枢内宽幅震荡，回退到 Extending
  │     • 回抽脱离 (u_{k+1} 仍未触及 [ZD, ZG]) ──> 确立第三类买卖点！当前中枢立即密封闭合 (Seal)
  │     • 外部成新中枢 ──> 当前中枢立即闭合 (Seal)
  │
  ▼
已闭合独立中枢序列 [C_0, C_1, C_2, ...]
  │
  ▼
【相邻对扩张归并 Pairwise Central Expansion (第 20 课定理二)】
  对走势相邻的 (C_i, C_{i+1})：
  • 若核心区间分离 (ZG_{i+1} < ZD_i 或 ZD_{i+1} > ZG_i)
  • 且波动极值重叠 (GG_{i+1} >= DD_i 或 DD_{i+1} <= GG_i)
  ──> 归并为更高级别中枢形态，防范无界级联多米诺串联
```

## 2. 数学公式与判据定义

### 2.1 中枢触及与延伸（第 20 课中心定理一）
设已确立中枢的当前核心区间为 $[ZD, ZG]$。
对于后续输入单元 $u = [low, high]$：
- **触及（Touch）**：$high \ge ZD$ 且 $low \le ZG$（几何区间存在交集）。
- **完全离开（Depart）**：
  - 向上离开：$low > ZG$
  - 向下离开：$high < ZD$

延伸时，中枢区间 $[ZD, ZG]$ 动态维护为当前窗口内所有构成单元的公共重叠交集：
$$ZD = \max(low_1, low_2, \dots, low_n), \quad ZG = \min(high_1, high_2, \dots, high_n)$$
波动极值维护为全量极值：
$$DD = \min(low_1, low_2, \dots, low_n), \quad GG = \max(high_1, high_2, \dots, high_n)$$

### 2.2 第三类买卖点与中枢闭合（第三类买卖点定理）
- **向上破坏（第 3 类买点）**：
  离开单元 $u_k$ 满足 $low_k > ZG$；随后的反向回落单元 $u_{k+1}$ 满足 $low_{k+1} > ZG$。
- **向下破坏（第 3 类卖点）**：
  离开单元 $u_k$ 满足 $high_k < ZD$；随后的反向回抽单元 $u_{k+1}$ 满足 $high_{k+1} < ZD$。

**闭合动作**：
当前中枢 $C$ 在离开单元 $u_k$ 之前正式截断闭合；中枢所有几何参数与构成单元集合固化；算法指针前进至离开处继续寻找下一个新中枢。

### 2.3 中枢扩展（9 单元结合，第 52/57 课）
当一个中枢在延伸过程中，未发生破坏且持续累积达到 9 个构成单元（如 9 笔或 9 段，即 $3+3+3$ 结合）：
- 该中枢标记为中枢扩展（`expanded: true`）；
- 视作更高一级别的走势中枢完成，同级别生命周期结束并闭合。

### 2.4 中枢扩张（第 20 课中心定理二）
仅在相邻已闭合的同级别独立中枢 $(C_A, C_B)$ 之间判定：
1. **中枢区间严格分离**：
   $$\max(C_A.zd, C_B.zd) > \min(C_A.zg, C_B.zg)$$
2. **波动极值区间重叠或相切**：
   $$\max(C_A.dd, C_B.dd) \le \min(C_A.gg, C_B.gg)$$

命中扩张时，归并为高级别中枢 $C_{AB}$，区间取 $[ \max(dd_A, dd_B), \min(gg_A, gg_B) ]$，`expanded: true`。扩张仅作用于直接相邻走势对，禁止无限制递归级联整段行情。

## 3. 算法复杂度与稳定性

- **时间复杂度**：从原先的 $O(N^2)$ 滑窗枚举与全局定点合并，优化为 $O(N)$ 单遍顺序状态机扫描推进。
- **确定性**：无任何外部状态或随机性，同一输入序列必然产出严格唯一的中枢序列。
- **内存安全**：零过度分配，单遍流式推进。
