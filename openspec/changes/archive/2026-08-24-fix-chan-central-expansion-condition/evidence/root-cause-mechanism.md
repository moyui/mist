## 机制链：段级 600519 逐步推演

### 步骤 1：Phase A 滑窗步进 1 → 同一个段序列枚举出 7 个"中枢"

9 个段 D0~D8（D2 是暴涨段 [1142.29, 1834.49]）。3 段滑窗、步进 1：

| 窗口 | 构成段 | 区间 [zd, zg] |
|------|--------|---------------|
| W0 | D0,D1,D2 | **[1421.14, 1671.41]** |
| W1 | D1,D2,D3 | [1321.53, 1606.36] |
| W2 | D2,D3,D4 | [1321.53, 1475.04] |
| W3 | D3,D4,D5 | [1362.02, 1475.04] |
| W4 | D4,D5,D6 | [1362.02, 1475.04] |
| W5 | D5,D6,D7 | [1362.02, 1514.06] |
| W6 | D6,D7,D8 | **[1293.99, 1363.35]** |

按缠论，中枢区间由前 3 个次级别走势重叠确定后**固定**。这里同一段序列给出
7 个不同区间——它们不是 7 个中枢，而是同一个盘整区的 7 个候选窗口。区间漂移
是枚举策略的副产物，不是缠论语义。

### 步骤 2：延伸重算区间 → 漂移加剧

`extendChannel`（duan-channel.ts:197）尾部 +2 段后用
`validateChannelGeometry(新窗口)` **重算** zd/zg：

| 窗口 | 段数 | 区间（重算） |
|------|------|-------------|
| W0 | 3 (D0~D2) | [1421.14, 1671.41] |
| W0 延伸 | 5 (D0~D4) | **[1421.14, 1475.04]** ← zg 从 1671.41 漂到 1475.04 |

缠论语义：延伸只应更新波动极值 gg/dd 与时间边界，**zd/zg 保持前 3 段确定值不变**
（开源实现 czsc/chan-lun 均如此：`zs.gg = max(...); zs.dd = min(...)`，从不改区间）。

当前实现把延伸后的新区间当"新中枢"，进一步制造漂移候选。

### 步骤 3：共享极端段 → 波动区间必然重叠

D2 暴涨段（[1142.29 → 1834.49]）同时存在于 W0~W2 的波动极值中：

- W0 波动 [1142.29, 1834.49]
- W4 波动 [1293.99, 1539.98]

尽管区间分离（1363.35 < 1421.14，见 W6 vs W0），波动区间因共享 D2 而重叠。

### 步骤 4：isCentralExpansion 只查波动重叠 → 误判扩张

```typescript
return Math.max(prev.dd, next.dd) <= Math.min(prev.gg, next.gg);
// 只看波动重叠 → M0/M1（区间分离的漂移候选）被判成扩张对 → 合并巨型
```

合并产物 = 全区间巨型（[1142.29, 1834.49]，9 段，2024-01 ~ 2026-08）——即前端看到的"太夸张"。

## 根因陈述（供 fix-chan-central-expansion-condition 定案）

1. **枚举层**：Phase A 滑窗步进 1 + Phase B 延伸重算区间 → 同一盘整区被枚举为
   多个区间漂移的候选中枢（假对来源）。根本方案应"区间固定"（延伸只更新 gg/dd）
   并收敛滑窗枚举（如跳过式滑窗）。
2. **判定层**：`isCentralExpansion` 只查波动重叠，缺中心定理二的**中枢区间分离**
   条件（`max(prev.zd,next.zd) > min(prev.zg,next.zg)`）。
3. 两层均需修复：①消除假对、③ 精确定义合法扩张——二者独立成立，无法互相替代。
