# 中枢扩张误判问题 —— 问题与现状记录

> 本文档记录 `audit-chancore-algorithms` §6 发现的中枢扩张误判问题从发现、复现到机制分析
> 的全部现状，供后续方案讨论使用。**本文档只记录问题与现状，不定案解决方案。**
> 日期：2026-08-23。数据：600519 TDX 日线 2024-01-01 ~ 2026-08-20（1240 根，backend `/v1/indicators/k`）。

---

## 1. 问题概述

`libs/chancore/src/internal/central-expansion.ts` 的中枢扩张（Phase C）判定
`isCentralExpansion` 只检查两个中枢的**波动区间**（`dd..gg`）重叠
（`max(prev.dd, next.dd) <= min(prev.gg, next.gg)`），在真实数据下把本不构成扩张的
中枢对错误合并为 `expanded=true` 巨型中枢。笔级（`createChannels`）与段级
（`createDuanChannels`）均受影响。

## 3. 缠论原文依据

第 20 课中心定理二（逐字引自 `stockServ/chzhshch-108-plus`，evidence 见
`audit-chancore-algorithms/evidence/chan-textbook-excerpts.md`）：

> 前后同级别的两个缠中说禅走势中枢，后GG〈前DD等价于下跌及其延续；后DD〉前GG等价于上涨及其延续。
> **后ZG<前ZD且后GG〉=前DD，或后ZD〉前ZG且后DD=<前GG，则等价于形成高级别的走势中枢。**

即扩张 = **中枢区间（ZG/ZD）严格分离 + 波动区间（GG/DD）重叠（含相切）**，且前提是"前后同级别"
（趋势里连续产生的两个中枢）。

另：中心定理一（延伸语义）——中枢的延伸等价于任意区间 [dn, gn] 与 [ZD, ZG] 有重叠；
中枢区间 `[ZD, ZG]` 由前 3 个次级别走势确定（`ZG=min(g1,g2)`, `ZD=max(d1,d2)`）。

## 4. 机制分析（三层）

### 4.1 判定条件缺失（审计 §6 原始发现，笔级案例的根因）

`isCentralExpansion` 只检查波动区间重叠，漏了中心定理二的**中枢区间分离**条件。
笔级 B0/B1 区间重叠 → 按原文不构成扩张 → 现行判定错误合并。

### 4.2 滑窗枚举冗余（步进 1）→ 中枢区间随窗口漂移

Phase A 枚举策略：`i++` 步进 1，每个起点都尝试（代码注释"枚举所有重叠/相邻候选中枢"）。
同一段序列因此产生**区间不同**的重叠窗口。600519 段级 3 段滑窗 7 个窗口的区间
依次为 [1421.14, 1671.41] / [1321.53, 1606.36] / [1321.53, 1475.04] /
[1362.02, 1475.04] / [1362.02, 1475.04] / [1362.02, 1514.06] / [1293.99, 1363.35]——
区间随窗口位置漂移。

### 4.3 延伸时重算区间 → 漂移加剧

`extendChannel`（channel.ts:152 / duan-channel.ts:197）延伸尾部/头部 ±2 单元后，
用 `validateChannelGeometry(延伸后窗口)` **重算** `zg/zd`——区间随延伸继续漂移。
缠论语义下区间应由前 3 段确定后**固定**，延伸只更新波动极值 `gg/dd` 与结束时间
（开源实现 czsc/chan-lun 均如此：`zs.gg = max(zs.gg, xd.high); zs.dd = min(zs.dd, xd.low)`，
从不改 `zd/zg`）。

### 4.4 段级假对（M0/M1）的成因

M0/M1 由 4.2 + 4.3 的区间漂移产生：同一段序列（D0~D8，含暴跌 D1 与暴涨 D2）的
不同窗口/延伸组合，得到区间分离（1363.35 < 1421.14）但波动区间必然重叠（共享暴涨段
D2 [1142.29, 1834.49] 撑大两者波动极值）的假中枢对。旧判定按波动重叠合并 →
全区间巨型。M0/M1 **共享构成段 D2~D7**，不是原文"前后同级别"的两个中枢，而是同一
段窗口序列的不同枚举——"前后"前提不成立，扩张概念不适用。

## 5. 验证过程中纠正的认知

| 认知 | 纠正 |
|------|------|
| 段级 Phase B（mergeSpans）在真实数据下产 7 个重叠宽段中枢 | **错误**（早前复现脚本用数字常量替代 status 枚举导致配置偏差）。插桩真实代码路径：mergeSpans 归并良好，输出 2 个中枢（M0/M1） |
| "隔 7 根笔、近 3 个月"是笔级误判的根因 | 不是。根因是 B0/B1 中枢区间重叠（round trip），7 笔间隔是伴随现象 |
