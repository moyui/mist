## 6. 笔中枢扩张判定缺陷（2026-08-23，可视化审计发现）

### 现象（前端 /chan-tests 可视化确认）

600519 TDX 日线（2024-01 ~ 2026-08）Phase B 仅产出 **1 个 expanded=true 巨型中枢**（2024-05-06 ~ 2025-02-06，12 笔）。用户肉眼判断"太夸张"：应拆为
- 中枢①：2024-06-24 ~ 2024-08-09
- 中枢②：2024-11 之后

### 数据证据

Phase A 枚举出 6 个基础中枢，其中前两个：

| 中枢 | 时间范围 | 笔 | 波动区间 [dd, gg] |
|------|----------|-----|-------------------|
| [0] | 2024-05-06 ~ 07-30 | 笔[5]~[9] | [1306.56, 1454.47] |
| [1] | 2024-11-07 ~ 2025-02-06 | 笔[17]~[21] | [1342.36, 1504.22] |

两中枢之间隔了 **7 根笔、近 3 个月**（07-30 ~ 11-07），包含：
- 笔[11] 08-08~09-19：大跌至 1142.29
- 笔[12] 09-19~10-07：暴涨至 1834.49（+60%）
- 笔[13]~[16]：10 月回落震荡

当前 `isCentralExpansion` 判定：`max(1306.56,1342.36) <= min(1454.47,1504.22)` → 波动重叠 → 扩张 → 6 个全部合并为 1 个。

### 缠论原文（第 20 课「缠中说禅走势中枢级别扩张及第三类买卖点」）

> **中心定理二**：前后同级别的两个缠中说禅走势中枢，后GG〈前DD等价于下跌及其延续；后DD〉前GG等价于上涨及其延续。**后ZG<前ZD且后GG〉=前DD，或后ZD〉前ZG且后DD=<前GG，则等价于形成高级别的走势中枢。**

原文扩张条件 = **中枢区间（ZG/ZD）分离** + **波动区间（GG/DD）重叠**，且前提是**前后同级别（相邻）**中枢，即趋势中连续产生的下一个中枢（中间只有次级别离开段），不是隔 3 个月 + 一段暴涨暴跌独立行情之后的老中枢。

### 缺陷定位

`libs/chancore/src/internal/central-expansion.ts`：

```typescript
// 当前实现——只检查波动区间重叠
export function isCentralExpansion(prev, next): boolean {
  return Math.max(prev.dd, next.dd) <= Math.min(prev.gg, next.gg);
}
```

**缺失条件**：
1. 未检查**中枢区间 ZG/ZD 分离**（原文：后ZG<前ZD 且 后GG>=前DD，或镜像）——两个中枢区间相交时应视为延伸/同一中枢，不是扩张
2. 未检查**相邻性**（中间不能有构成独立走势的笔数/行情）
3. 段级 `mergeDuanCentralExpansion` 同缺陷（无相邻性检查）

### 修复方向（待用户确认后进入实施计划）

- `isCentralExpansion` 增加中枢区间分离校验（使用 zd/zg 而非 dd/gg）
- `resolveCentralExpansions` 或调用方增加相邻性约束（如：next 首笔须紧邻 prev 末笔，或中间笔数 ≤ 阈值）
- 段级同步
