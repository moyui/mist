# Proposal: audit-chancore-algorithms

## 背景

缠论核心算法（`libs/chancore/`）已实现笔/段/中枢/背驰/买卖点全套计算，单元测试覆盖充分。
但此前仅在模拟/构造数据上验证，未系统性地用 **真实 TDX/QMT 市场数据** 端到端验证算法输出
与缠论原典定义的一致性。

## 目标

对 `ChanCore` 全链路（K 合并 → 笔 → 段 → 笔中枢 → 段中枢 → 背驰 → 买卖点）进行
**只读审计**，不修改任何生产代码。
